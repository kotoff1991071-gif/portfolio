# Портфолио

Одностраничник и презентация на 7 слайдов. Чистый HTML, CSS и JS — ни сборки,
ни зависимостей, ни конструкторов. Папку можно просто залить на любой
статический хостинг.

## Что где лежит

```
index.html            сайт
deck.html             презентация, печатается в PDF из браузера
404.html
assets/
  css/style.css       токены, типографика, вёрстка сайта
  css/deck.css        раскладка слайдов и стили печати
  js/content.js       ← имя, контакты, цены и сроки. Правь только здесь
  js/main.js          подстановка значений, меню, появление секций
  fonts/              Unbounded и Manrope, свои файлы (не с чужого CDN)
  img/                постер первого экрана и иконка
demo/
  dennochka/          «Деньночка» — интерфейс приложения как есть
  kotobol/            «Котобол» — PWA целиком
```

## Что нужно заполнить перед публикацией

Открой `assets/js/content.js` — всё помечено словом `TODO`:

- имя и две-три буквы для логотипа;
- ссылка на Телеграм и ник текстом;
- цены и сроки по четырём пакетам;
- адрес сайта, когда появится домен.

Скрипт подставит эти значения и на сайт, и в презентацию. В HTML лежат те же
значения запасным текстом — на случай выключенного JS; если они разойдутся,
побеждает `content.js`.

Осталось за пределами `content.js`:

- `robots.txt` и `sitemap.xml` — там прописан адрес `username.github.io`;
- `og:image` в `index.html` — картинку для превью в мессенджерах ещё не делали,
  сейчас тега нет совсем (лучше, чем ссылка в никуда);
- текст кейсов — он в `index.html` и `deck.html`, это проза, а не настройки.

## Как посмотреть локально

Просто открыть `index.html` двойным кликом достаточно для вёрстки, но
service worker «Котобола» по протоколу `file://` не работает. Чтобы всё было
по-настоящему, подними любой статический сервер в папке проекта, например:

```bash
npx serve .
```

## Как опубликовать на GitHub Pages

1. Создай репозиторий и залей туда содержимое папки.
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет по адресу `https://<логин>.github.io/<репозиторий>/`.
4. Свой домен: положи рядом файл `CNAME` с одной строкой — доменом, и пропиши
   у регистратора записи, которые покажет та же страница Pages.

Файл `.nojekyll` уже лежит в корне — без него Pages игнорирует папки,
начинающиеся с подчёркивания, и иногда ломает статику.

## Презентация в PDF

Открыть `deck.html` → `Ctrl + P` → «Сохранить как PDF». В настройках печати
включить **фоновую графику**, иначе слайды будут белыми. Должно получиться
ровно 7 страниц A4 в альбомной ориентации.

## Про анимацию

Пока её почти нет — это прототип. Есть только плавные ховеры, медленный дрейф
фоновых свечений и появление секций при прокрутке.

Задел под большее уже стоит: у блоков класс `.reveal`, в `main.js` работает
`IntersectionObserver`, который вешает `.is-visible`, а все движущиеся стили
лежат в конце `style.css` внутри `@media (prefers-reduced-motion: no-preference)`.
Добавлять анимацию можно туда, не трогая разметку.
